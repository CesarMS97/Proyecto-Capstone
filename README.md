# Proyecto Capstone

## Plataforma de Gestión Técnica Eléctrica (PGTE)

**Sistema para el levantamiento, registro y cotización de servicios eléctricos.**

---

## Descripción del proyecto

La **Plataforma de Gestión Técnica Eléctrica (PGTE)** es una solución informática orientada a técnicos y empresas del área eléctrica, cuyo objetivo es digitalizar y centralizar el proceso de levantamiento de información durante una visita técnica.

El sistema permite registrar las características de una vivienda, sus instalaciones y componentes eléctricos, generando una **ficha digital del hogar** que puede ser utilizada como base para la elaboración de cotizaciones y recomendaciones técnicas.

La propuesta busca reducir el uso de registros manuales, facilitar la organización de la información y mejorar la trazabilidad de los servicios eléctricos realizados.

---

## Objetivo

Desarrollar un sistema web que permita a técnicos eléctricos:

- Registrar información de clientes y propiedades.
- Realizar levantamientos técnicos de instalaciones eléctricas.
- Registrar componentes y características de los tableros eléctricos.
- Mantener una ficha digital de cada vivienda.
- Generar información estructurada para cotizaciones.
- Consultar y mantener un historial de los registros técnicos.

---

## Alcance del proyecto

El proyecto contempla el desarrollo de un **MVP (Producto Mínimo Viable)** enfocado en las principales necesidades del proceso de levantamiento técnico.

### Módulos principales

- Gestión de clientes.
- Gestión de propiedades.
- Levantamiento eléctrico.
- Registro de componentes eléctricos.
- Ficha digital del hogar.
- Generación de cotizaciones.
- Consulta de información registrada.
